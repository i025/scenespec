# M2 开发集机制消融：运行前协议

基线 `46d87dc`。不修改 M0/M1/M2、任务、资产、MeshWorld、eligible 或执行器；不调用提案模型，不生成 M3。本轮不读取私有验证/终测任务，也不据已报告终测进行参数选择。

固定输入为已公开 `experiments/m2_failure/results/pilot/dev_cases.json` 的 8 个开发条件及每条件原有两个种子。每个运行仍恰好 24 次 Mesh/像素查询，独立最终物理/通行评分保持不变。候选只能在通过现有八项安全回归的 Apptainer LayoutProcess 内执行。先重跑原有 236 项测试和隔离验收。

预先固定下列程序干预，不根据本轮结果选择新参数：

| 组 | 相对完整 M2 生成算法的唯一干预 |
|---|---|
| group_restart | 重跑原始初始生成器，作为历史数值与时间对照 |
| full | 原始候选不变；核对全部开发状态与旧记录一致 |
| no_initial_yaw | 仅第零次 heuristic 初始化 yaw 置零；照常消耗对应 RNG 抽样，重采样 yaw 不变 |
| no_projection | 偶数查询丢弃关系投影更新，输出前一重采样状态；影子投影仍消耗原 RNG，不把空出的查询重新分配 |
| no_restarts | 奇数查询丢弃分组重采样更新，保留 incumbent；照常生成随机提案，不重新分配查询 |
| one_projection_pass | 关系投影每次从六轮减为一轮；随机调用路径随之改变，这是整个轮数干预的效果 |
| no_initial_yaw_no_projection | 上述两项组合，用于 2×2 交互检查 |

`no_projection` 和 `no_restarts` 保留影子计算是为了尽量耦合随机流；这是对输出机制的干预，不是实际删算后的速度基准。其后的适应性路径仍可能分歧。主随机种子相同不代表整个适应过程始终使用相同随机数。

另在 full 的同一条已保存自适应轨迹上，将最终 minimum optimizer_loss 改为 first/last query-valid 选优。query-valid 仅指查询评分无 failures，不能替代最终物理/通行成功；所有替代输出重新经过原 MeshWorld(final=True)。不改未来 incumbent，不据替代选择重新搜索，因此这是最终筛选的受控反事实，不是整个自适应搜索的消融。额外最终重评分数与时间单列，不冒充额外生成查询或部署候选。

报告偏好误差、硬成功、位置/旋转多样性、可见比例、合法配对、时间、CPU、查询数、运行错误，并给出 8 个任务聚类的配对差及描述性 95% bootstrap 区间。多样性沿用原 evaluator 的同任务双种子距离和同资产置换匹配。没有把 16 次生成当成 16 个独立多样性样本；小样本区间不作跨任务机制的普遍因果证明，不进行显著性筛选或阈值调整。

冻结验收阈值只用于描述开发指标是否满足旧规则，不选择或部署新程序。交互固定为 2×2 差中差。报告整段轨迹与最后选优的分布变化；不能用配对均值变化推断某个物体必然发生遮挡。本轮止于机制解释与下一轮方法建议。
