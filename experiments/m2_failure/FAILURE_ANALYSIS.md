# 原有四个候选的 dev 失败机制分析（零新模型调用）

只读取 `526a309` 已公开的 dev 状态与 24 步查询轨迹，重建六套程序（两组 Repair 与四个候选）的保存输出。没有执行候选、调用模型或增加 Mesh 查询。重建的最小 optimizer_loss 状态与所有保存的最终状态完全相同。原始评分器和多目标阈值不变。

| 历史组 / 算法 | 平均提案位置多样性 m | 平均 incumbent 多样性 m | 最终输出多样性 m | 最终偏好误差 m |
|---|---:|---:|---:|---:|
| 0 / Repair | .5402 | .3945 | .4534 | .2391 |
| 0 / M0 | .3981 | .1998 | .2791 | .0839 |
| 0 / M1 | .4777 | .3169 | .3615 | .0719 |
| 1 / Repair | .5388 | .3785 | .4660 | .3100 |
| 1 / M0 | .4839 | .3370 | .4256 | .0900 |
| 1 / M1 | .3910 | .1843 | .2919 | .0945 |

平均提案指标是在两个种子的同一查询号之间比较，再对 24 步与 8 个条件平均；incumbent 是每步运行到当时的最低 loss。两者与最终分布不同，不应混成一个“多样性分数”。

**搜索算法因素。** 四个程序都保留 seeded RNG/getstate/setstate 和随机重采样，没有固定种子表或完全确定性输出。三个每三步投影的候选，双种子同时投影时的提案多样性分别为 .1964、.3556、.1810m，非投影时为 .4990、.5481、.4961m；距离投影倾向于压缩位置分布，同时降低误差。0/M1 先随机重采样再精修，投影/非投影槽分别 .4812/.4705m，不能把“投影总会降低提案多样性”当成普遍规律。

**生成器内部选择因素。** 所有程序沿用最低单次 optimizer_loss 的历史选优，搜索又从这个 incumbent 继续。固定同一条记录轨迹，改取“最后一个查询有效布局”时四个候选的位置多样性为 .5200/.4394/.6557/.5684m，但偏好误差回升到 .3245/.2141/.4976/.4394m。改取最低偏好误差布局也没有稳定恢复多样性。候选池中仍存在变异，低误差选优可能进一步收缩输出；这不是简单的 RNG 消失。

这些替代选择是对同一已自适应生成的候选流重放，未重新生成反事实搜索，也未对未选状态补做最终物理/通行验收。因此它们支持机制假设，不能定量分离“提案更新”与“历史选优”的因果贡献，更不能宣称替代选择器通过硬约束。

**几何限制并非充分解释。** 最终触及 floor zone 边界的比例由基线 .7813/.5625 降为候选 .4063/.3750/.3750/.4375。不能只因代码含 clamp 就把退化归为边界挤压。相似目标距离、共同低误差区域、旋转 footprint 与选优共同作用是待验证解释。支持物上的物体位置也计入原始多样性度量，并按原评价的等价物体匹配处理。

**外部候选版本选择。** 独立验证的原规则拒绝四个程序并保留 Repair，没有把它们的分布退化部署为新版本。外部接受门槛不是观察到的原始候选多样性损失的制造者，也不应为接受它们而放宽门槛。需要区分它与生成器内部的 final index 选择。

**元策略信息处理。** M1 的旧 `_brief` 和 `_features` 主要处理可靠性、推箱子尺寸/难度和错误类别，未直接提炼当前连续布局的偏好/跨种子分布指标。这是代码观察，尚非机制优势的因果证据。后续共同适配将同样的配对指标与历史 dev 失败统计提供给全部 M0/M1/M2；不只给 M2 更多信息。
