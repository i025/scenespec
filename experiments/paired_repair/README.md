# 两组 Repair 配对：未发现 M1 的多目标改进优势

从 `0e30ebb` 继续；协议、代码、dev 基线与预算在真实推理前提交为 `157c255`。完成两组独立 M0/M1 配对，K=1，共 **4 个真实原生 Codex 编码任务、14 次服务请求**，没有追加候选、真实能力测试或 M2。所有候选完整、静态审计通过、隔离执行无错误；M0/M1 的验证集接受率均为 **0/2**，新的私有终测多目标通过数也均为 **0/2**。

**本轮数据不支持 M1 比 M0 更有效地发现兼顾质量与多样性的算法改进。** 两者都降低了偏好误差，但都未保持足够的位置多样性。M1 在第一组多样性较好、第二组较差，没有重复一致的优势，且实际 Token 消耗更多。没有继续调用模型寻找正结果。

## 固定条件与接受规则

M0、M1、`gpt-6.1-sol` medium、CLI 0.163.0 和原生编辑工具保持不变；只给原始 Repair，不使用上一轮候选。共同任务适配、dev 反馈、探测/示例选择继续调用原有 `request_for`；两组均为 M0 random、M1 dense。没有给模型人工分析得到的修复提示。

每组使用原有 8 个公开 dev 条件、独立新建的 8 个私有验证条件和 12 个私有终测条件，每条件两个算法种子。同组 M0/M1 的初始源码、条件和种子完全相同；两组分别采样条件/算法种子和独立模型会话。因此组间变化同时包含模型采样及任务/种子变化，不是纯粹固定任务的模型方差实验。40 个私有参考布局均通过原 MeshWorld；未复用上一轮私有任务。它们是同一冻结分布的新条件，不是新资产或新任务族的外推。

在提案前记录两组 dev 基线并冻结原有 `eligible`，没有重新搜索阈值：硬成功数不下降、无运行错误、可见性下降不超过 .01、全配对及合法配对位置多样性各保留至少 90%、旋转多样性至少 80%、合法配对数不下降，在此前提下偏好误差至少降低 .01 米。按此固定规则相对于各组独立验证基线进行选择。dev 不另加事后否决条件，成本单独报告，不用加权总分掩盖多样性损失。

验证集选择封闭后才运行全部终测。未通过验证的候选仍做终测以报告算法质量，但不能因终测表现补选。最终版本回退初始 Repair，不把回退成绩当候选改进。

## 算法修改与验证结果

四个候选都加入了输入相关的三维目标距离投影，按物体高度把三维距离目标转为水平距离，并按旋转 footprint 限制端点位置；保留随机搜索，不是切换 METHOD 或改几个参数。

- 0/M0：每三轮穿插端点随机分摊、最多 12 轮距离投影。
- 0/M1：保留随机重采样，在已有合法布局后穿插 4 轮、按关系误差加权的精修。
- 1/M0：加入平面扰动、随机移动权重和最多 48 轮关系投影。
- 1/M1：每三轮加入最多 6 轮、随机分摊移动量的距离投影。

源码/diff、Git 版本、说明、JSONL、调用统计与实际审计结果分别位于 [0/M0](results/pair0/c0)、[0/M1](results/pair0/c1)、[1/M0](results/pair1/c0)、[1/M1](results/pair1/c1)。原始基准算法没有被这些候选覆盖。

按验证集冻结的最终选择，M0/M1 两组都保留 Repair，所以偏好误差配对差值为 `[0, 0]`，均值、样本标准差、范围均为 0。这来自选择了同一初始算法，不是证明两种元策略等价。最终硬成功均为 48/48；最终偏好误差跨两组均值 `.21028m`、样本标准差 `.02817m`；位置多样性均值 `.53836m`、样本标准差 `.07146m`。没有最终可接受生成能力提升。

组内任务聚类 bootstrap 在 [scores](results/pair0/scores.json)、[paired comparisons](results/paired_comparisons.json) 中，描述任务采样的不确定性；两组的模型样本量仍是 n=2，不能把 48 次场景输出当 48 次独立元策略试验。位置多样性也是每条件两个种子的有限估计，不等于完整布局分布覆盖。

这里不是 Joint 的误差地板：Repair 验证/终测误差有改善空间，四个算法都实际降低了误差。代价是布局分布收缩。它们均使用相同 24 次 Mesh/像素查询，不是通过额外查询、可解性拒绝采样、资产缩放或改评分获得收益；内部解析迭代量有变化。现象说明这批固定策略产生的候选没有达到预定多目标要求，尚不能判断 M1 的某个机制具有因果优势。
